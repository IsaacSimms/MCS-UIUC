# Intro to Cloud Computing Concepts and Course Overview

## Note
CS 425 is NOT about how to use cloud systems or build programs for the cloud, that is covered in Cloud applications. It is also not about cloud networking.
Both of those are separate courses.
This course is about getting under the hood of the distributed systems that underlie modern cloud computing tech. Distributed techniques, concepts, algorithms, etc. that are used today.
This class is also not an Azure or AWS cert, not a vendor lock in.
Focus on, and be thinking about, core design philosophies, techniques, so on and so forth that are used in companies, in open source environments, and in personal use.
