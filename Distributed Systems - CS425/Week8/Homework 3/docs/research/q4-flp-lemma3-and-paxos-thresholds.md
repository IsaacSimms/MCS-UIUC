# FLP Lemma 3 Case II, which events the proof allows, and unequal Paxos thresholds

## Answer

**i.** Case II really does allow \(p' = p\). Set \(C\) is the set of configurations reachable from the bivalent apex while the single event \(e = (p, m)\) stays unapplied. An event is one receipt, the pair \((process, message)\). Keeping \(m\) in the buffer leaves every other event legal, including a different step \(e' = (p, m')\) of the same process \(p\). That step stays inside \(C\), and it is exactly the neighbor the proof writes as \(C_1 = e'(C_0)\) with \(p' = p\).

The proof reaches that neighbor as follows. Assume, for contradiction, that every configuration in \(D = e(C)\) is univalent. Bivalence of the apex puts both a 0-valent and a 1-valent configuration into \(D\). Configurations in \(C\) are connected by single events, so on a path in \(C\) from a configuration whose \(e\)-image is 0-valent to one whose \(e\)-image is 1-valent, the valency of the image flips across some one-event edge. Call the endpoints \(C_0\) and \(C_1\), with \(C_1 = e'(C_0)\), \(e' = (p', m')\), \(D_0 = e(C_0)\) 0-valent, and \(D_1 = e(C_1)\) 1-valent. The slide asks “(why?)” at this line; the published lemma answers it by that neighbor argument. Nothing in the path forces \(p'\) to differ from \(p\). When the crossing edge is another step of \(p\), the proof is in Case II.

Case II then uses a finite deciding schedule \(s\) that starts at \(C_0\) and in which \(p\) takes no steps. One crash is allowed, and total correctness was assumed to decide anyway, so such an \(s\) exists. Let \(A = s(C_0)\). The processes that move in \(s\) are disjoint from \(p\), so Lemma 1 (disjoint schedules commute) lets \(s\) pass through \(e\) and through \(e'\): \(s(e(C_0)) = e(A) = E_0\) is 0-valent, and \(s(e(e'(C_0))) = e(e'(A)) = E_1\) is 1-valent. Both are reachable from \(A\), so \(A\) is bivalent. The run that reaches \(A\) is deciding, so \(A\) is univalent. That contradiction means the assumption is false: \(D\) contains a bivalent configuration.

The silence of \(p\) belongs only to the schedule \(s\) that extends \(C_0\). It is a different fact from the way \(C\) was built. \(C\) omits the one delivery \(e\); \(s\) is a later deciding run in which \(p\) is the crashed process.

**ii.** Yes. On the triangle, any event \(e\) that is applicable to the bivalent configuration at the apex can be the event in the proof. The lecture introduces it as “some event applicable to the initial config,” and the published Lemma 3 quantifies over every event applicable to a bivalent configuration. The written cases never require a particular process, a particular message, or an event that is about to decide.

Applicability is the characteristic the argument uses. Because messages may be delayed arbitrarily, an event applicable at the apex stays applicable at every configuration in \(C\), which is why every point of the triangle has an \(e\)-arrow into \(D\). In Case II the one-fault hypothesis supplies a deciding schedule that skips whichever process is named in that \(e\). The same process is allowed to be the silent one no matter which applicable \(e\) was selected.

The picture is drawn on a bivalent initial configuration. The lemma statement beside it is “starting from a bivalent config,” and the steps above use bivalence, one fault, and commutativity of disjoint schedules. They do not use any further property of the apex being initial, so the same proof applies again at later bivalent configurations. The infinite admissible run that finishes the theorem does later pick a particular \(e\) at each stage (the earliest buffered message of the process at the head of a queue, or a null receipt). That selection is how the theorem applies the lemma so that every process takes infinitely many steps and every message is delivered. It is outside the proof drawn on the triangle.

**iii.** This version is safe for every positive integer \(N\).

In this course, Election is Phase 1 and Bill is Phase 2. A round has chosen a value at the point of no return, which is a Bill quorum accepting the proposal, before the Law announcement. The safety proof is: a later Election quorum intersects that Bill quorum, so at least one Election reply carries the accepted value \(v'\) (the latest such value, if several arrive), and the new round proposes \(v'\) or fails. Classic Paxos gets the intersection by making both quorums majorities. The same proof needs only that every Election set meets every Bill set.

Take the thresholds as written. They are integers together exactly when \(N = 3k\) for an integer \(k \geq 1\): Election size \(k+1\), Bill size \(2k+1\). Their sum is \(N+2\), so any such pair of sets has at least \(2\) processes in common. Checked algebraically for every multiple of \(3\), and directly for \(N \in \{3,6,9,12,15,30,99\}\).

For \(N\) not divisible by \(3\), \(N/3+1\) and \(2N/3+1\) are not integers. Reading the implementation in integer arithmetic as \(\lfloor N/3 \rfloor+1\) and \(\lfloor 2N/3 \rfloor+1\), the sizes still sum to \(N+1\) or \(N+2\):

- \(N = 3k\): sum \(N+2\)
- \(N = 3k+1\): sum \(N+1\)
- \(N = 3k+2\): sum \(N+1\)

So the intersection is nonempty for every \(N \geq 1\). That reading was also checked by enumeration for every \(N\) from 1 through 300. Rounding a non-integer threshold upward only enlarges a quorum, which preserves the intersection.

Lamport’s proof uses this same intersection and no other. A chosen proposal \(m\) with value \(v\) has been accepted by a Bill set \(C\). Any higher proposal \(n\) is issued only after its proposer has heard from an Election set \(S\). Because \(S \cap C \neq \emptyset\), some acceptor in \(S\) has accepted a proposal numbered in \(m \ldots (n-1)\), and the proposer must reuse the value of the highest-numbered one among those replies. One ballot carries one value: ballot ids are unique, and distinct proposers draw numbers from disjoint sets. Disjoint Election quorums, which do exist for \(N = 3k\) with \(k \geq 2\) (two sets of size \(k+1\) fit in \(3k\)), are two different ballots. They do not let two Bill quorums choose different values, because a completed Bill set of size \(2k+1\) cannot miss a later Election set of size \(k+1\).

## Recommendation

Use the three arguments above as the worked solution. The part worth weighing is (iii): the lecture states the proof with majorities, and these thresholds are not majorities, but the intersection the proof actually invokes still holds, so the agreement property survives. What changes is liveness headroom. A Bill quorum of \(2N/3+1\) is larger than a majority for every \(N > 3\), so a round needs more live processes before a value is chosen. The homework asks only whether the version is safe, and in this course safety means that consensus is not violated.

## Ruled out

- The reading “\(C\) contains no steps of process \(p\).” The lecture and the paper both define \(C\) by omitting the single event \(e = (p, m)\). Other events of \(p\), including a null receipt, remain applicable inside \(C\). That is why Case II exists.
- The reading that Lemma 3 needs a distinguished event (oldest message, deciding step, or a fixed process). The triangle is quantified by applicability. The oldest-message rule appears only in the theorem’s construction of an admissible infinite run, after the lemma.
- Treating this implementation as the review question on the same Paxos deck: “everywhere there was a quorum (\(> N/2\)), the new implementation only requires \(> N/3\).” That shrinks both phases. For \(N = 4\), size 2 already admits disjoint sets; for \(N = 6\), size 3 does too. A later Election quorum can then miss a chosen Bill quorum. Homework 3 keeps Bill at \(2N/3+1\), and those two sets cannot be disjoint. — [T2] Lecture 18-A review question 3 (https://courses.grainger.illinois.edu/cs425/fa2026/L18.A.FA26.pdf)
- Requiring the two Election quorums to intersect each other before calling the algorithm safe. For \(N = 3k\), \(k \geq 2\), two Election sets of size \(k+1\) can be disjoint. The course proof and Lamport’s P2c induction use the intersection of a later Election (phase 1) set with an earlier Bill (phase 2) accept set. Unique ballot ids already give one value per round.
