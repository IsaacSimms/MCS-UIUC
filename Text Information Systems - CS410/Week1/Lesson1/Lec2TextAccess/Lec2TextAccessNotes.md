Remember, bag of words is still very popular in search engines. 

Let us say that we have done or bag of Words and NLP on the data set. How can the text information system allow users to actually be served relevant data to their query?
### two strategies
    Push (querying and browsing)
    vs
    pull
#### Pull
e.x. a search engine
users are taking initiative and have control over direction
user has ad hoc need for information or need for something that the system does not already know about them.
Common when information need is temporary
##### Querying
User enters key word --> system returns relevant results.
Works well when user knows exactly what they are working for.
Know exactly what you want? query.
##### Browsing
System establishes path of information based on the structure of documents and data and relationships between datapoints.
User navigates that path in an attempt to find relevant information to what they are looking for. (but may not know keywords for)
do not know exactly what you are looking for? browse.

#### Push
e.x. a recommendation system
the system takes initiative in what is served to the user.
the need for information is stable, repetitive, and well known and / or the system has good knowledge on what the user wants at any given time.

**These can be combined... user looks something up ad hoc (pull happens) --> system takes that, assumes some other thing is related and serves that as well (push happens.)
