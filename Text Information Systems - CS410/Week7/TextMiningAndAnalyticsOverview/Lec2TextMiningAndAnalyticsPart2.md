# Text mining: focus of mining in this class

## Defintion
Text mining is a form of data mining. The same problems and theory apply.
- raw data --> useful decisions
- Input = natural-language text
- Output = text derived from generation process
- Real world --> (perspective is gained, often by humans. *human sensor*) --> observed world (what is represented in human has. ) --> expressed as natural language such as english --> text data
*Models such as LLMs are also now able to create text data*

-  **The goal of text mining is to reverse the above process**
1. Could take one hop back, mining information about the language
2. Could take two hops back, to mine the content that is in a set of text data
3. Could take three hops back, mining knowledge about the observer that generated the text data
4. Could also take four hops back to infer information about the real world based on the text data. (predictive analytics)

### Role of non-text data
Non-text data can also provide supplementary context that allows you to make decisions.
- align text with external events or measurements
- compare text accross metadata such as time periods or locations associated with the text data
- build predictions models that use both text-derived features and non-text features
