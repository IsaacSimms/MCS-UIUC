# Text Mining and Text Analytics
There are subtle differences but we will be using them interchangablely here. 
- Analytics focuses more on results
- Mining focuses more on process

## define
Turn text data into high-quality information or antionable knowledge (concise and easy to consume)
- Minimize human effort 
- Supply knowledge for optimal decision making
**Text retrieval can be a preprocessor for text mining.** (TR is generally considered an essential componenet in text mining)

## Human as sensors
Text is generated by humans observing the world and expressing what they perceive. This is different from non-text data produced by physical sensors. (temperature, location, etc.)
*Text data here refers to natural-langauge text.*
*Non-text data can still be a form of characters, such as structured measurements. (Numerical, categorical, relational, video, etc.*

- text data in this context is useful for mining knowledge about people, attitudes, and opinions
- it can be jointly analyzed with non-text data in the same context
- Small amounts of text can be high-value bc they directly encode value

## The general problem of data mining
Text mining and data mining of various other types need to both be able to get completed in an efficient way. Then, data mining software needs to be built and used in order to analyze that mined data in some way to produce actionable knowledge.
