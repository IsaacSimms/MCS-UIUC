## 1. Which of the following is NOT a use of text clustering?

**Context.** Text clustering groups items according to the similarity of their textual content (documents, words, or web pages represented as vectors). It does not operate on non-text modalities.

**Correct answer.** Grouping similar pictures together.

**Why.** Pictures are images. Clustering them is image clustering (or content-based image retrieval). The other three options are standard uses of text clustering: document clustering, word clustering, and clustering websites by their textual content.

## 2. Which of the following is true about the maximal likelihood of a set of documents?

**Context.** In the unigram / multinomial models used for documents (and inside PLSA), likelihood depends only on word counts, not on word order. Any transformation that preserves the multiset of words leaves the maximum likelihood unchanged.

**Correct answer.** If we have a document "w1 w2 ... wn" changed into "wn ... w2 w1", the maximal likelihood does not change.

**Why.** Reversing order leaves every word count identical, so both the document likelihood and the collection’s maximum likelihood stay the same. Doubling tokens changes the counts; globally swapping two word identities re-labels the vocabulary and therefore changes which parameter settings achieve the maximum.

## 3. Which of the following is correct about K-means and PLSA?

**Context.** Both algorithms partition data into a user-chosen number of groups and both are iterative procedures whose results can depend on initialization. K-means alternates assignment and centroid update; PLSA uses EM to estimate topic-word and document-topic distributions.

**Correct answer.** Both algorithms require the user to specify the number of clusters/topics.

**Why.** K (clusters) and Z (topics) must be set in advance. The other statements are false: both algorithms are iterative, and both can produce different results from different initializations.

## 4. What is the disadvantage of using a model-based clustering algorithm?

**Context.** Model-based clustering assumes documents are generated by a mixture of probabilistic components (one per cluster/topic). Similarity is defined implicitly by the form of those component distributions and is estimated by maximizing likelihood (normally via EM).

**Correct answer.** It is difficult to substitute a different similarity measure.

**Why.** The generative assumptions fix the notion of closeness. Changing the similarity requires changing the model itself. In contrast, similarity-based methods (ordinary K-means, hierarchical clustering, etc.) accept an arbitrary distance or similarity function. Training speed and raw performance are not the distinctive structural disadvantage.

## 5. What is the difference between direct and indirect evaluation for a clustering algorithm? (Check all that apply)

**Context.** Direct evaluation compares a clustering against a human-annotated gold-standard partitioning using metrics such as purity or NMI. Indirect evaluation inserts the clustering into a downstream application and measures the application’s performance.

**Correct answers.**
- Indirect evaluation requires a user specified application to test with.
- Direct evaluation requires a human annotated gold standard cluster.

**Why.** Those two statements accurately describe the two evaluation regimes. The claim that direct evaluation is inherently better is not true in general; each approach answers a different question.
