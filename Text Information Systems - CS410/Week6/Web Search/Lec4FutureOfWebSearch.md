# The future of web search
**There are many potential opportunities for improvement in the search space**

- Search engines will become more specialized/customized (vertical search engines)
    Specialized group of users per engine. 
    Personalized
    Specialized domain
- Learning over time (ML)
- Integration of search, navigation, and recommendation/filtering into one thing. 
- Search becoming an integral part of other tasks such as shopping or job hunting

## DUS triangle
- Often, intelligent information systems can be thought of as three nodes:
- Data (What kind of data are you managing? File types? Web pages? Literature?)
- Users (who are you serving? Lawyers? Tech professionals? General public?)
- Services (What is it that you are providing? explicit search? Browsing? Mining?)
These three things connected is the information system. These things can be connected in different ways.
